# Мағжан Жұмабаев — қазақтың ұлы ақыны

Қазақ тілі, 6-сынып. Интерактивті сабаққа арналған сайт және ҚМЖ.

Оқу мақсаттары:
- 6.1.5.1 – тірек сөздер, жетекші сұрақтар, мәтін тақырыбы арқылы негізгі ойды анықтау
- 6.5.1.4 – өздік, болымсыздық, белгісіздік, жалпылау есімдіктерін жазба, ауызша жұмыстарда орынды қолдану

## Файлдар
- `index.html` — сайттың өзі (теория, ақын өмірі, 3 тапсырма, ойындар, зияткерлік алаң, рефлексия, үй тапсырмасы, ҚМЖ)
- `kmzh-magzhan.docx` — ҚМЖ, Word форматы (сайттағы «Word жүктеу» батырмасы осы файлды жүктейді)

## GitHub Pages арқылы жариялау
1. GitHub-та жаңа репозиторий ашыңыз (мысалы, `magzhan-site`), **Public** етіп қойыңыз.
2. **Add file → Upload files** арқылы `index.html`, `kmzh-magzhan.docx`, `README.md` файлдарын жүктеп, **Commit changes** басыңыз.
3. **Settings → Pages** бөліміне өтіңіз.
4. **Source**: `Deploy from a branch`, **Branch**: `main`, папка: `/ (root)` → **Save**.
5. 1–2 минуттан кейін сайт мына мекенжайда ашылады:
   `https://<сіздің-логин>.github.io/magzhan-site/`
